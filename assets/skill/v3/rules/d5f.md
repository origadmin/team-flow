# Code Review Rules (d5f)

## Required Actions

1. **Architecture Check**: Verify alignment with system architecture
2. **Security Review**: Check for security vulnerabilities
3. **Maintainability**: Assess code quality and readability
4. **Compliance**: Verify adherence to coding standards

## Deliverables

- Review checklist completion
- Action items list (if any)
- Approval sign-off

## Gate Conditions

- All blocking issues must be resolved
- Reviewer must approve the changes
- No security vulnerabilities identified
