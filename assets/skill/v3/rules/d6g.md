# Deployment Rules (d6g)

## Required Actions

1. **Environment Check**: Verify target environment readiness
2. **Rollback Plan**: Document rollback procedure
3. **Change Management**: Follow change control process
4. **Monitoring**: Set up post-deployment monitoring

## Deliverables

- Deployment checklist
- Rollback plan document
- Post-mortem template (for incident response)

## Gate Conditions

- Staging environment validation complete
- Rollback plan approved
- Change request approved (if required)
