# 任务启动文档模板

> 任务创建时，Triage 创建任务目录和启动文档
> 启动文档作为任务的索引和追踪中心，所有后续产出物都在启动文档中维护

---

## 目录结构

```
{docs_internal}/tasks/{TaskID}/
├── 00-INIT.md          # 启动文档（索引 + 追踪）
├── 01-{阶段1}.md      # 阶段报告 1
├── 02-{阶段2}.md      # 阶段报告 2
├── ...
└── 99-CLOSE.md        # 关闭报告
```

---

## 启动文档模板

```markdown
# 任务启动文档

**任务 ID**: {TaskID}
**任务类型**: feature / bugfix / docs / analyze
**创建者**: Triage
**创建时间**: {YYYY-MM-DD HH:mm}

---

## 一、问题来源

| 项目 | 内容 |
|------|------|
| **原始报告** | {用户原始描述} |
| **报告来源** | 用户反馈 / 自动检测 / 代码审查 |
| **复现步骤** | {如何复现} |
| **期望行为** | {用户期望} |
| **当前行为** | {实际行为} |

---

## 二、产出物索引

> 所有阶段产出物都在此索引，按时间倒序排列
> 新增产出物时，插入到表格顶部

| 阶段 | 角色 | 产出物 | 路径 | 完成时间 |
|------|------|--------|------|----------|
| 任务创建 | Triage | 启动文档 | `00-INIT.md` | {YYYY-MM-DD HH:mm} |
| <!-- 新增产出物在此插入 --> | | | | |

---

## 三、文档变更记录

> 涉及样式、规范等文档的变更记录
> 修改任何规范文档时，必须在此记录

| 变更文档 | 变更类型 | 变更点 | 变更原因 | 变更者 | 变更时间 |
|---------|---------|--------|---------|--------|----------|
| <!-- 示例：ui-standards.md \| 修改 \| 按钮高度 h8→h10 \| Bug 修复 \| Dev \| 2026-04-22 --> | | | | | |

---

## 四、当前状态

| 项目 | 内容 |
|------|------|
| **当前阶段** | 任务创建 |
| **当前负责人** | Triage |
| **状态** | Todo / Doing / Blocked / Review |
| **下一步行动** | 移交给执行角色 |

---

|---------|---------|---------|------|------|---------|--------|---------|------|----------|
```

## 维护规则

### Triage（任务创建时）

```
1. 创建任务目录：{docs_internal}/tasks/{TaskID}/
2. 创建启动文档：00-INIT.md
3. 填写问题来源、里程碑关联
4. 初始化产出物索引（只有启动文档）
5. 设置当前状态为 Todo
```

### 各角色（阶段完成时）

```
1. 创建阶段报告：{序号}-{阶段名}.md
2. 更新启动文档：
   - 在产出物索引顶部插入新行
   - 更新当前状态
3. 如修改了规范文档：
   - 在文档变更记录中添加新行
```

### 角色发起协作请求时

```
1. 填写协作请求表格（必须完整：输入/输出/完成标准/优先级/期望时间）
2. 在协作请求记录表格添加新行
3. 创建协作子任务目录和启动文档
4. 更新协作状态追踪表格
5. 主任务状态改为 Blocked
```

### 协作角色完成时

```
1. 更新协作状态追踪表格（状态改为 已完成）
2. 更新协作结果摘要表格
3. 主任务自动解除阻塞
4. 通知主任务负责人
```

### Triage（任务关闭时）

```
1. 创建关闭报告：99-CLOSE.md
2. 更新启动文档：
   - 在产出物索引顶部插入关闭报告
   - 更新当前状态为 Closed
```

## AI 指令

### Triage 创建任务时

```
1. 在 task-pool 添加任务行
2. 创建任务目录：{docs_internal}/tasks/{TaskID}/
3. 创建启动文档：00-INIT.md
4. 填写问题来源
5. 初始化产出物索引
6. 设置当前状态
```

### 角色完成阶段时

```
1. 创建阶段报告：{序号}-{阶段名}.md
2. 更新启动文档：
   - 在产出物索引顶部插入新行
   - 更新当前状态
3. 如修改了规范文档：
   - 在文档变更记录中添加新行
4. 在 task-pool 更新产出物追踪表格
```

### 角色接手任务时

```
1. 读取启动文档：{docs_internal}/tasks/{TaskID}/00-INIT.md
2. 查看产出物索引，找到最新的阶段报告
3. 读取最新的阶段报告，了解上下文
4. 开始执行自己的工作
```

### 发起协作请求时

```
1. 填写协作请求表格（必须完整）
2. 在启动文档 → 协作请求记录 添加新行
3. 创建协作子任务目录和启动文档
4. 更新协作状态追踪表格
5. 主任务状态改为 Blocked
```

### 协作角色完成时

```
1. 更新主任务启动文档：
   - 协作状态追踪 → 状态改为 已完成
   - 协作结果摘要 → 添加结果摘要
2. 主任务自动解除阻塞
3. 通知主任务负责人
```
