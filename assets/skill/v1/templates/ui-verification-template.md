## 截图规则

### 保存路径

```
{docs_internal}/reports/bugs/B{NNN}-R{N}/screenshots/
```

### 命名规范

```
B{NNN}-R{N}-{步骤编号}-{动作}-{状态}.png
```

| 部分 | 规则 | 示例 |
|------|------|---------|
| B{NNN} | Bug ID | B099 |
| R{N} | R 迭代 | R1 |
| {步骤编号} | 3位数字 | 001, 002, 003 |
| {动作} | 用户操作 | click-submit, type-email, navigate-dashboard |
| {状态} | before / after / result | before, after, result |

**示例**:
- `B099-R1-001-navigate-login-before.png` — 修复前登录页
- `B099-R1-002-click-submit-result.png` — 点击提交按钮后
- `B099-R1-003-check-dashboard-result.png` — 仪表盘页面显示修复生效

### 截图数量

| Bug 类型 | 最少截图数 | 必须内容 |
|----------|-----------|----------|
| UI 渲染 Bug | 2 | 修复前 + 修复后 |
| 交互 Bug（点击/输入/提交） | 3 | 操作前 + 操作中 + 操作后 |
| 导航/路由 Bug | 2 | 错误页面 + 正确页面 |
| 数据显示 Bug | 2 | 错误数据 + 正确数据 |
| 表单验证 Bug | 3 | 空表单 + 无效输入 + 有效提交 |
| 多步骤流程 Bug | N+1 | 每步 + 最终结果（N = 步骤数） |

### 截图质量

- 分辨率: 1280x720 最低（桌面端），375x812（移动端如适用）
- 格式: PNG（不是 JPEG，不是 SVG）
- 内容: 全页面或聚焦区域，需包含足够上下文
- 必须显示: URL 栏（用于导航验证）、元素状态（用于交互验证）
