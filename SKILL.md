# team-flow v3 — Entry Point

> **Version**: v3.1 | **Date**: 2026-05-21

## Quick Start

```bash
# Initialize in a new project
flow init --v3

# Migrate from v2
flow migrate v3

# Start the flow engine
flow proc run
```

## Installation

### Via flow CLI (Recommended)

```bash
flow init --v3
```

This uses embedded skill files — no network required.

### Via npm

```bash
npx skills add @origadmin/team-flow
```

## Compatible AI Tools

Claude Code, Cursor, Trae, Windsurf, GitHub Copilot, OpenCode, OpenClaw, Cline, Gemini CLI
