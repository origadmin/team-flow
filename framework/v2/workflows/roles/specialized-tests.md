# 专项测试触发规则与检查项 — v2 beads-native

> **后端 8 类专项测试**

---

## 触发判断流程

扫描变更文件，逐条匹配以下触发条件。命中则标记"必须测"。

---

## 专项测试清单

### 1. E2E 测试

**触发条件**：涉及核心主链路、跨模块流程、登录/鉴权、下单/支付等闭环。

**检查项**：
- [ ] 从真实入口走完整流程
- [ ] 前后端/服务间调用正常
- [ ] 状态流转完整
- [ ] 最终结果正确

### 2. 接口/API 测试

**触发条件**：新增或修改接口、字段、错误码、分页、过滤、鉴权。

**检查项**：
- [ ] 入参校验
- [ ] 出参结构
- [ ] 状态码和错误码
- [ ] 鉴权
- [ ] 幂等性
- [ ] CRUD 完整流程

### 3. 权限与安全

**触发条件**：涉及登录态、角色、资源归属、敏感字段。

**检查项**：
- [ ] 未登录访问 → 拦截
- [ ] 越权访问 → 拦截
- [ ] 角色差异
- [ ] 敏感字段不泄露

### 4. 并发/幂等/重试

**触发条件**：涉及扣减、提交、回调、状态流转。

**检查项**：
- [ ] 重复提交不重复生效
- [ ] 重试安全
- [ ] 并发下状态不错乱

### 5. 数据一致性

**触发条件**：涉及数据库、缓存、队列、任务状态。

**检查项**：
- [ ] 主表与明细一致
- [ ] 缓存与数据库一致
- [ ] 事务成功/失败/回滚后数据正确。

### 6. 异步任务/队列

**触发条件**：涉及消息队列、定时任务、死信。

**检查项**：
- [ ] 消息不丢失
- [ ] 不重复消费
- [ ] 死信不堆积。

### 7. 配置与兼容性

**触发条件**：涉及配置开关、环境变量、灰度、老数据。

**检查项**：
- [ ] 开关开启/关闭都符合预期
- [ ] 老数据可正常使用。

### 8. 回滚与可观测性

**触发条件**：涉及上线发布、迁移脚本、灰度策略。

**检查项**：
- [ ] 回滚方案可执行
- [ ] 关键日志齐全
- [ ] 指标和告警能发现问题。
