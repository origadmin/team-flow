# 变更类型→测试级别映射 — v2 beads-native

> **适用**: 所有代码变更的质量判定

---

## 变更类型判定

### 后端变更类型

| 变更类型 | 判定标准 |
|---------|---------|
| 纯逻辑调整 | 仅修改单文件/单函数内部逻辑 |
| 接口改动 | 新增或修改 API 端点、请求/响应字段 |
| 跨模块改动 | 变更涉及 2 个以上模块/包 |
| 核心链路改动 | 变更涉及登录/鉴权/支付等核心入口 |
| 高风险改动 | 涉及数据迁移、架构重构 |

### 前端变更类型

| 变更类型 | 判定标准 |
|---------|---------|
| 纯样式调整 | 仅修改 CSS/Tailwind 类名 |
| 组件逻辑调整 | 修改组件内部状态、事件处理 |
| Hook 变更 | 新增或修改自定义 Hook |
| API 调用变更 | 新增或修改 API 请求 |
| 页面/路由变更 | 新增页面、修改路由结构 |

---

## 测试级别定义

| 级别 | 覆盖要求 |
|------|---------|
| 单元测试（P0） | 函数/方法的正常/异常/边界路径 |
| 模块测试（P0） | 组件与直接依赖联动行为 |
| 接口/API 测试（P1） | 入参校验、出参结构、状态码、鉴权 |
| 集成测试（P1） | 跨模块调用链、事务一致性 |
| E2E 测试（P2） | 完整业务流程、跨页面状态流转 |
| 安全测试（P1） | XSS/注入/权限绕过 |
| 兼容性测试（P2） | 历史数据、浏览器、移动端 |
| 性能测试（P2） | 响应时间基线、并发稳定性 |

---

## 提测准入基线

### 后端提测准入

| 变更类型 | 必须完成 |
|---------|---------|
| 纯逻辑调整 | 单元 + 模块 + 回归 |
| 接口改动 | + API 测试 + 兼容性 |
| 跨模块改动 | + 集成测试 + 数据一致性 |
| 核心链路改动 | + E2E + 专项测试 |
| 高风险改动 | + 性能基准 + 回滚演练 |

### 前端提测准入

| 变更类型 | 必须完成 |
|---------|---------|
| 纯样式调整 | 视觉验证 + 响应式 |
| 组件逻辑调整 | 单元 + 交互测试 |
| Hook 变更 | Hook 单元 + 边界值 |
| API 调用变更 | MSW 集成 + CRUD 流程 |
| 页面/路由变更 | 路由守卫 + 页面渲染 |
| 全局状态变更 | 状态管理 + 跨组件集成 |
